# Hogger.IO

Desktop companion for World of Warcraft—addons, character data, and runs in one place.

## Downloads

Installers are published on **[Releases](https://github.com/Shaneciora/Hogger.IO/releases)**. Pick the build for your system:

| Platform | Typical file |
|----------|----------------|
| **macOS** | `.dmg` or `.zip` (Apple Silicon builds are common on recent runners; use the archive that matches your Mac) |
| **Windows** | `.exe` (installer or portable, depending on the release) |
| **Linux** | `.AppImage` |

Always use the **latest release** unless you need an older version for troubleshooting.

## Requirements

- **macOS**, **Windows 10/11**, or a recent **64-bit Linux** distro  
- **Network access** for game and API features (where applicable)

## Security & trust

- Builds are produced by automation and attached to tagged releases here.  
- Installers may be **unsigned** in early releases; your OS may show a warning. Only download assets from **this repository’s Releases** page.

## Repository role

**This repo is the public home for downloadable builds.** Source code stays private; when a version is ready, CI publishes binaries to **Releases** so anyone can install without access to the development repositories.
